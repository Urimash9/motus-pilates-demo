# Motus Pilates — final visual assets

These image assets are stored as **text SVG wrappers with embedded WebP data**.

Why this format:
- Git/Codex/connector friendly: the repository sees UTF-8 text instead of opaque binary files.
- Browser friendly: use directly in `<img src="assets/motus-final/<file>.svg">`.
- No external hotlink dependency.
- Optimized WebP payloads keep file sizes reasonable while preserving visual quality.

## Usage map
- `motus-hero-studio-wide.svg` — Hero / opening visual.
- `motus-manifesto-movimento.svg` — Manifesto / human movement support.
- `motus-espaco-wide.svg` — O Espaço / main environment image.
- `motus-espaco-detalhe.svg` — O Espaço / vertical equipment detail.
- `motus-movimento-controle.svg` — Movimento na prática / Controle.

These are AI-assisted visual assets built from Motus project references. Do not present them as documentary photographs of a specific client/person. Keep real Motus photos wherever authenticity is more important than art direction.
