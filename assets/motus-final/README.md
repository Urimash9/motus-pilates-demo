# Motus Pilates — Assets V1

Os arquivos de imagem finais da Build 01.11 ficam fora do Git como binários e são registrados aqui por um manifesto UTF-8.

## Por que assim
- evita erros futuros de binários em conectores/Codex;
- mantém o repositório leve e legível;
- preserva as imagens em armazenamento de mídia durável;
- o site pode usar diretamente os URLs do `manifest.json`;
- nenhum hotlink de Instagram/Gympass é necessário para estes assets.

## Pasta de mídia
`Motus Pilates — Assets V1`

## Mapa de uso
- `motus-hero-studio-wide` — Hero / abertura institucional.
- `motus-manifesto-movimento` — Manifesto / apoio humano.
- `motus-espaco-wide` — O Espaço / imagem principal.
- `motus-espaco-detalhe` — O Espaço / detalhe vertical.
- `motus-movimento-controle` — Movimento na prática / Controle.
- `motus-movimento-precisao` — Movimento na prática / Precisão.
- `motus-movimento-fluidez` — Movimento na prática / Fluidez.
- `motus-movimento-flexibilidade` — Movimento na prática / Flexibilidade.

## Implementação
Ler `assets/motus-final/manifest.json` e usar o campo `url` do asset correspondente no `src` da imagem.

## Importante
Os assets acima são imagens visuais assistidas por IA, criadas a partir das referências do projeto Motus. Não devem ser apresentados como fotografia documental de uma cliente ou aluna real específica. Fotos reais da Motus continuam preferíveis quando autenticidade documental for mais importante do que direção visual.
